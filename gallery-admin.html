Advanced

Getting a token (2 minutes)

  1. Sign in to GitHub and open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. (Developer settings is the last item in the left sidebar of Settings.)
  2. Give it a name like BSAUU gallery and an expiry date (e.g. the end of your term).
  3. Resource owner: the account or organisation that owns the website repository.
  4. Repository access: “Only select repositories” → pick the website repository.
  5. Permissions → Repository → Contents: set to Read and write. Nothing else is needed.
  6. Generate, copy the token, and paste it here.

Each committee member can use their own GitHub account, as long as they've been added to the repository (or the organisation) with write access. The token only ever goes to GitHub. Don't tick “Remember me” on a shared computer.
